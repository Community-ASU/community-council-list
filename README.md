# ASU Community Council Partner Ledger

This repository is a working portfolio ledger for organizations listed in `asu_community_council.json`. Each organization receives its own folder and Markdown profile so reviewers can quickly understand what the organization does, whether it appears in the FY25 Valley of the Sun United Way funded partner reference, and who the primary executive leader is.

Profiles are being created one organization at a time from the ASU Community Council list. Each completed profile follows the same structure:

- Organization name
- FY25 Valley of the Sun United Way funded partner status
- About
- Mission & Vision
- Executive Leadership

Executive leadership is limited to the CEO or primary leader listed in `asu_community_council.json`. When a verified photo is available, it is saved inside that organization's `images/` folder and referenced locally from the Markdown file. When a photo cannot be verified, the profile says `Photo not available`.
